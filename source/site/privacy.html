PrivacyLast updated: September 2026

What stays on your device

Worlds, settings and key bindings are stored in your browser (IndexedDB and localStorage) on the device you play on. They never leave it unless you export a world file yourself. Clearing the site's data in your browser deletes them.

What the game sends

Nothing, by default. The game contains no analytics, advertising, tracking pixels or third-party scripts, and it makes no network requests after the page has loaded. It works fully offline.

Multiplayer

If you choose to join a multiplayer server, the game sends that server the player name you typed, your position, the blocks you change and the chat messages you write, because that is what multiplayer is. The server operator can see this data; FABLE's bundled server keeps it in memory only and writes no logs of chat by default. Only join servers run by people you trust.

Hosting

The web host that serves this page may keep ordinary access logs (IP address, browser, time of request) as every web server does. Check your hosting provider's policy for details.

Children

The game collects no personal data and has no accounts, so there is nothing to consent to. Chat exists only on multiplayer servers you deliberately connect to.

Contact

Questions about this page: use the contact address published on the store or repository page where you found FABLE.
